# social-posts

Daily AI & Excel/Tally tips (English + Tamil) for Instagram @bh_arath1843 and YouTube Shorts.

- `tools/make_short.py spec.json out.mp4` builds a 1080x1920 Short (text scenes, Tamil + English voice, original background music).
- `tools/tts.py` voice (Google, en/ta); `tools/music.py` royalty-free music generator.
- `videos/YYYY-MM-DD/` holds each day's spec and video (public raw URL is used by Metricool to publish).
