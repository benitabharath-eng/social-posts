Excel Tip #20 for Accountants 📊
Show amounts in Indian lakhs format — 12,34,567 instead of 1,234,567!

Custom format (copy as ONE line):
[>=10000000]##\,##\,##\,##0;[>=100000]##\,##\,##0;##,##0

1️⃣ Select the amount column
2️⃣ Press Ctrl+1 → Number → Custom
3️⃣ Paste the format in the "Type" box → OK ✅

Result: 1234567 → 12,34,567 and 123456789 → 12,34,56,789. Only the look changes — the real number stays the same, so totals still work.
